Synchronisation…

Ton suivi est privé : il vit dans le dépôt privé recherche-emploi-candidatures. Pour le synchroniser entre tes appareils et le laisser mettre à jour par le robot, colle un jeton GitHub personnel (fine-grained, accès à ce dépôt privé, permission Contents : Read and write). Il reste sur cet appareil et n'est jamais publié. Sans jeton, ton suivi reste local à cet appareil.

Astuce : ajoute des offres depuis l'onglet Offres (bouton « Suivre »), ou saisis-en une ci-dessus. Déplace une carte avec le menu « Statut » (ou en la glissant sur ordinateur).
